# Commit = save a snapshot

1. Edit files. They appear under **Changes** (M = modified, U = new, D = deleted).
2. Click a file to review the change (red = removed, green = added).
3. Optional: press **+** to *stage* only the files you want in this commit.
4. Type a short message, e.g. *"Add contact form"*, and press **Commit** (Ctrl+Enter).

Made a mistake? **Undo Last Commit** puts everything back into staged changes.
