# Push to GitHub

**Publish to GitHub** creates a new repository on your account (choose *Private* to keep it to yourself) and uploads your commits.

After that:
- **Push** ↑ uploads new commits,
- **Pull** ↓ downloads commits made elsewhere (e.g. on your other computer),
- **Sync** does both.

Sign-in uses VS Code's built-in GitHub account — no tokens to copy.
